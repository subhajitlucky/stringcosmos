# StringCosmos 🌌

An interactive, visual-first educational microsite for mastering string algorithms.

## Features

- **Visual-First Learning**: Every algorithm is explained step-by-step with interactive visualizations.
- **Algorithm Playground**: Test Naive Matching, KMP, and Z-Algorithm with your own inputs.
- **Concept Map**: A structured learning path from basic encoding to advanced matching techniques.
- **Dark Mode Support**: Beautifully designed UI with system preference persistence.
- **Educational Diagrams**: Visual representations of ASCII, UTF-8, Prefix Tables, and Z-Arrays.

## Supported Algorithms & Topics

- **Basics**: ASCII, UTF-8, Unicode, String representation.
- **Pattern Matching**:
  - Naive Brute-Force Matching
  - Knuth-Morris-Pratt (KMP)
  - Z-Algorithm
- **Coming Soon**: Rabin-Karp (Rolling Hash), Suffix Arrays, Aho-Corasick.

## Tech Stack

- **React + TypeScript**
- **Vite** (Bundler)
- **Tailwind CSS** (Styling)
- **Framer Motion** (Animations)
- **Lucide React** (Icons)

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

## Design Philosophy

Treat string algorithms as processes, not formulas. StringCosmos prioritizes correctness, clarity, and intuition over text-heavy explanations.
